## 决策状态约定

- **A**：已确认的架构约束。
- **B**：研究推荐或候选方案，未自动获得批准。
- **C**：需要隔离实验或真实环境验证。
- **D**：需要用户作出的产品方向、权限或政策决定。

实验通过只能更新对应的 C 类证据，不能自动把 B 升级为 A；AI 或执行者不得替用户关闭 D 类事项。[第六批决策记录](../batch6/DECISIONS.md)是历史批次基线，**不是最新全部决策的唯一入口**。权限现行状态参见 [D01/D02 权限判定矩阵](../product/PRD-D01-D02-PERMISSION-DECISION-MATRIX-2026-11-01.md)；画布方向参见本目录 2026-11-01 决策。任何新增结论先核对用户批准与当前模块契约。
