# 方案与研究

这里负责**尝试方案到底行不行**：把明确的研究问题、供验证的方案与候选技术拿来调查、实验、比较，记录结果和限制。

- 可以记录已获同意开展研究的候选方案、开源参考、实验方法、工具与环境、结果/失败、替代路径、成本与风险。
- 严格区分「已同意研究」「已经做过实验」「实验观察通过」「用户最终确认采用」：四者不是同一种状态。
- 实验未成功、证据不足或受环境限制时直接标注，不推断代码已具备产品能力。
- 研究形成的正式设计与版本归属，由后续产品整理环节按用户确认另行处理；不自动修改模块 README、契约或任务书。

已归档的研究资料入口：[既有研究总索引](既有研究/README.md)，包括 API 历史/兼容验证、能力全景、安全与 Windows 生命周期、历史契约研究。
