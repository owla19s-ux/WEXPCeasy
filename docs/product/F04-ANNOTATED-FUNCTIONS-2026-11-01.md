## 功能注释与最小验收

### F04-001｜Provider 配置

- **需求状态：** A（沿用原总表）
- **可见 / 可操作 / 内部：** 用户可新增、修改、停用、测试某个具名 Connection；可看到所属 Provider、协议与端点；底层修订校验不可直接操作。
- **定义与歧义注释：** Provider 是协议/厂商描述；Connection 是用户独立配置。同一 Provider 可有多个不同端点/账号；重命名不改稳定 ID；修改不得重定向在途请求。
- **输入→输出及 Owner：** 连接编辑及预期修订 → 配置新修订；connections/api 拥有非秘密配置。
- **不包含：** 不包含 Key 明文存储、授权核发、其它连接器通用 Operation。
- **最低验收（正常 / 拒绝 / 异常）：** 正常：两连接互不覆盖；拒绝：修订冲突；异常：停用拒绝新调用但旧请求结果仍留证。
- **细分 ID：** 暂引用现有 API-01～10 锚点；具体更细业务编号待模块 owner 核定。
- **实现 / 验证：** WEXPCeasy 当前未证实对应正式实现；APS/WEXPC 旧代码与测试按历史资料独立追踪。

### F04-002｜账号与凭证引用

- **需求状态：** A（沿用原总表）
- **可见 / 可操作 / 内部：** 用户可选择/更换受保护凭证，可见引用有效/失效；无法直接读取明文；内部按请求解析凭证。
- **定义与歧义注释：** 账号、Provider、Connection、Key 非一一对应；配置仅保存 CredentialRef；删除连接不能误删共享秘密。
- **输入→输出及 Owner：** CredentialRef 与请求资格 → 受控凭证可用性事实；秘密值 owner 为 shared/credentials。
- **不包含：** 不含明文入聊天、普通日志或导出；不因有 Key 自动取得调用授权。
- **最低验收（正常 / 拒绝 / 异常）：** 正常：轮换凭证后新请求用新修订；拒绝：无授权不可调用；异常：单 Key 解密失败不得抹除其他连接元数据。
- **细分 ID：** 暂引用现有 API-01～10 锚点；具体更细业务编号待模块 owner 核定。
- **实现 / 验证：** WEXPCeasy 当前未证实对应正式实现；APS/WEXPC 旧代码与测试按历史资料独立追踪。

### F04-003｜模型目录

- **需求状态：** B（沿用原总表）
- **可见 / 可操作 / 内部：** 用户可获取/刷新模型列表、手动添加模型 ID；可见来源、时间和失败；内部缓存查询。
- **定义与歧义注释：** 模型 ID 属于 Connection 的能力视图，不代表全局可用；远端不支持 list 时仍可手填。模型存在与生成测试通过是两件事。
- **输入→输出及 Owner：** Connection 与目录观察 → 模型候选、来源、时间；connections/api。
- **不包含：** 不自动认定目录内所有模型可生成、可调用工具或已获凭证。
- **最低验收（正常 / 拒绝 / 异常）：** 正常：两 Connection 的列表相互隔离；拒绝：非法模型标识；异常：目录超时后允许手添且保留错误。
- **细分 ID：** 暂引用现有 API-01～10 锚点；具体更细业务编号待模块 owner 核定。
- **实现 / 验证：** WEXPCeasy 当前未证实对应正式实现；APS/WEXPC 旧代码与测试按历史资料独立追踪。

### F04-004｜模型能力描述

- **需求状态：** B（沿用原总表）
- **可见 / 可操作 / 内部：** 用户可查看模型文本/视觉/音频/工具/推理/流式能力；内部基于能力决定请求可否发出。
- **定义与歧义注释：** 区分官方声明、用户填写、实际探测与未知；不能凭名称推断；输入媒体不支持时明确提示/拒绝，不可静默丢弃。
- **输入→输出及 Owner：** 能力来源与模型 ID → 能力投影及证据时间；connections/api。
- **不包含：** 不负责让模型获得尚不支持的模态，也不自动证明厂商履约。
- **最低验收（正常 / 拒绝 / 异常）：** 正常：已确认能力可匹配请求；拒绝：不支持图片时禁止静默忽略；异常：探测失败不判定模型不存在。
- **细分 ID：** 暂引用现有 API-01～10 锚点；具体更细业务编号待模块 owner 核定。

### F04-005｜调用参数配置

- **需求状态：** B（沿用原总表）
- **可见 / 可操作 / 内部：** 用户可启停和设定采样/输出/推理/自定义原生参数；可见支持状态；内部完成参数映射。
- **定义与歧义注释：** 区分服务端默认、显式值、不支持、未知、冲突；参数覆盖优先级仍需以历史研究与待决项确认。不同模型的 thinking budget/reasoning effort 原生语义不能粗暴统一。

- **最低验收（正常 / 拒绝 / 异常）：** 正常：参数映射正确；拒绝：冲突/不支持参数明确报错；异常：在途请求不受配置更新影响。

### F04-006｜连接测试与诊断

- **需求状态：** A/B（沿用原总表）
- **可见 / 可操作 / 内部：** 用户主动测试配置、模型目录、生成、流式及工具能力；可见测试层级和时间；内部受控派发。
- **定义与歧义注释：** 保存成功、可联网、能列模型、能生成、能用工具是不同事实。真实探测可能产生计费，须标明。
- **输入→输出及 Owner：** 测试目标/凭证引用/授权 → 层级结果与失败原因；connections/api 产生观察，connections 保存 Operation。
- **不包含：** 不将成功配置等同成功模型调用；不以失败一次认定永久不可用。
- **最低验收（正常 / 拒绝 / 异常）：** 正常：分层成功回执；拒绝：无调用权限零外发；异常：401/429/timeout 可区分且不泄漏正文。
- **细分 ID：** 暂引用现有 API-01～10 锚点；具体更细业务编号待模块 owner 核定。

### F04-007｜模型调用与流式适配

- **需求状态：** A（沿用原总表）
- **可见 / 可操作 / 内部：** 用户可请求生成、查看增量及最终结果、发起停止；内部拼帧、校验终态、原生续传。
- **定义与歧义注释：** 请求绑定 Provider/Model/参数/输入来源快照。SSE 文本/推理/工具参数分块不可误解释；取消本地读取≠服务端停算或免计费。

- **最低验收（正常 / 拒绝 / 异常）：** 正常：完整合法结束；拒绝：残缺 JSON 工具意图；异常：断流保留部分内容、unknown 不伪装 success。

### F04-008｜工具调用格式适配

- **需求状态：** A/B（沿用原总表）
- **可见 / 可操作 / 内部：** 用户可见模型提出的工具意图及执行结果；能否批准由权限/交互层决定；内部解析并关联轮次。
- **定义与歧义注释：** 模型提议不是执行，也不是授权。参数必须完整、Schema 合法、工具 ID 与当前生成关联；工具回传形成后续模型输入。
- **输入→输出及 Owner：** Provider tool call → WEX 结构化意图；connections/api 解释，permissions 判权，connections 负责工具 Operation。
- **不包含：** 不包含直接运行 shell/git、凭模型指令绕过授权或将提议写成已完成。
- **最低验收（正常 / 拒绝 / 异常）：** 正常：工具往返多轮；拒绝：未知工具/非法 JSON；异常：取消生成不推断正在进行的工具操作已回滚。
- **细分 ID：** 暂引用现有 API-01～10 锚点；具体更细业务编号待模块 owner 核定。

### F04-009｜模型路由与选择

- **需求状态：** B（沿用原总表）

- **定义与歧义注释：** 全局默认只影响新会话，修改路由不得偷偷换当前在途请求。换 Provider 可能改变数据出口，须单独检查来源限制。

- **最低验收（正常 / 拒绝 / 异常）：** 正常：能力匹配模型；拒绝：不可外发数据不换厂商；异常：无合格模型明确失败。

### F04-010｜限额与用量记录

- **需求状态：** B（沿用原总表）
- **可见 / 可操作 / 内部：** 用户可见 token、用量、估算费用及未知状态；不可手工改写 Provider 真实账单；内部记录来源。
- **定义与歧义注释：** Provider 返回值、SDK 推算、用户价格表估算和实际账单必须分列。未返回 usage/price 保持未知，不能写零。
- **输入→输出及 Owner：** 用量/价格来源/请求引用 → 带来源的观察记录；connections/api。

### F04-011｜超时、重试与降级

- **需求状态：** B/C（沿用原总表）
- **可见 / 可操作 / 内部：** 用户可见超时和尝试记录、按政策重新尝试；内部按错误性质判断资格。
- **定义与歧义注释：** connect/idle/total timeout 区别；超时不证明远端未处理或未计费；只有模型调用可按政策开启新 attempt，不连带重跑工具副作用。

- **不包含：** 不包含未知状态盲重发、默默重复执行工具、无证据标记取消成功。
- **最低验收（正常 / 拒绝 / 异常）：** 正常：明确可重试限流；拒绝：未知外部结果禁止盲重试；异常：断连保留原因及部分片段。

## 仍需细分但不能擅自定稿的横向子功能

- **Connection 管理**：复制/停用/删除影响、模型目录时间、凭证共享与轮换，按 F04-001/002/003 与 F05 生命周期相互引用，不新增第二套 Connection owner。
- **参数体系**：通用采样、原生字段、启停、省略、推理预算、能力矩阵、覆盖优先级和输入多模态，应逐条按 WEX A-005 历史专项与实验结果映射；尚不能视作全部批准。
- **协议描述文件**：WEX A-015～017 的扩展目标不能被 Pi AI SDK 动态 Provider 误认为已经满足；它需要独立的版本/校验/失败恢复细化，与 F12 插件系统区分。
- **生成链路**：正常流、推理增量、工具片段、结束原因、取消竞态、续传 scope、usage 来源，优先复用 WEXPC DEC-01～16 验收规范。
- **多模态**：图像/音频/视频/文件输入和结构化输出各有不同支持状态；Pi AI 对不支持图像可能静默忽略，WEX 必须明确阻断/提示。
