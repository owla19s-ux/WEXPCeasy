> **用途：长期工程导航及状态登记**。以既有 216 项功能编号、模块 CONTRACT 映射和 0.1.1 反向覆盖核验为基础，复用旧 Excel“功能/版本/模块”组合管理思路。**此稿并不宣称已核验 216 项源代码；所有“待逐项代码复核”均为待检查，不是没有源码。** 施工者不能据此自行追加版本范围或扩权。

## 0. 使用方法与权威边界

1. **用户提出新想法**先进入 [A0｜产品构想与研究](../A0-产品构想与研究/README.md)，讨论方案与可行性；**不自动加入施工**。
2. **正式产品需求**仍以 [F01～F15 产品功能总表](../product/PRODUCT-FUNCTION-CATALOG-2026-11-01.md) 为权威；当前已确认的 UI 布局/交互按 [PC UI V0.6](../product/WEX-PC-0.1.1-基础UI布局与交互设计-2026-11-07.md) 与 [UI 功能映射](../product/WEX-PC-0.1.1-UI功能映射与设计收口-2026-11-07.md) 审查。
3. **模块事实与源码职责**仍在对应源码目录 README、CONTRACT、公开接口和测试中定义；本表只索引，不复制接口/数据结构或修改归属。
4. **本表的版本列**仅复述此前审查得出的范围关系，**不是完整功能已被批准/交付，也不能替代** [0.1.1 正式计划](0.1.1/PLAN.md) 和 [B3 任务书](0.1.1/B3-DESKTOP-DELIVERY-TASK-2026-11-07.md)。
5. 当前 Codex **仍然是用户指定任务书 → 模块 README/CONTRACT → 代码/测试**；施工 AI 不自行修改本表、产品规格和版本文档。交回提交与测试证据，由验收/文档维护方核对后回写。
6. 旧 Excel（2026-10-31，93 个功能 ID、85 条首版规划、17 条后续版本候选、19 个模块映射、15 个待确认事项）是历史管理原型；曾经的 `0.1.1` 建议、完成进度和 Placement 设计**不能覆盖目前确认的 0.1.1 边界**，需逐项对冲才可迁移。暂不把旧 `FUT-001` 语音等候选直接纳入 0.1.2。

| 当前施工 | 从本表选出本次已批准的功能，再生成或引用具体施工任务；回执反填 | 未确认设计不派工，未验证不写“已验收” |
