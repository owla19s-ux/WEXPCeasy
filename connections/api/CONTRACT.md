# connections/api 业务子契约（2026-11-01）

- 上级owner：connections。此文件只细化Provider适配器，不创建第二Operation账本或新的顶层模块。
- 对应功能：F04-001～013，以及F03-008/F03-012。
- 状态：B候选语义；C实验与D政策保持未关闭。本文不冻结SDK、函数签名、wire、数据库schema或模型厂商协议。

## 1. Owner与对象边界

connections/api拥有Provider配置、模型目录/能力观察、请求协议适配、流式解析、厂商错误映射和usage来源记录。shared/credentials拥有秘密值；API只保存凭证引用。AI拥有Agent/角色配置和本次工作模型引用；conversations拥有逻辑生成、消息及输入快照；connections宿主拥有Operation/attempt/receipt/observation；workflows拥有Task/运行状态。Provider账号配置不等于WEX用户账号。模型工具意图是结构化提议，不是工具执行。

## 2. 能力子契约

| 锚点 | F映射 | 输入 | 输出/权威事实 | 生命周期与异常 |
|---|---|---|---|---|
| API-01 Provider配置 | F04-001 | Provider类型、端点、协议版本、非秘密参数、预期修订、凭证引用 | Provider连接配置修订、可用性观察 | 凭证明文不进入配置/日志；改配置不重定向在途请求；端点不可用与配置无效分开 |
| API-02 Model/Capability目录 | F04-003/004 | Provider实例、模型标识、能力探测/静态元数据 | 模型目录项、能力声明、来源和验证时间 | 未知能力不显示支持；探测失败不等于模型不存在；目录过期不冒充实时可用 |
| API-03 凭证与连接测试 | F04-002/006 | 凭证引用、目标Provider/Model、测试动作 | 凭证可用性/拒绝原因/请求观察 | 真实联网测试是受控Operation；Key不回显；凭证可解密不等于权限允许 |
| API-04 请求与流式解析 | F04-007、F03-008 | 本轮模型快照、输入、参数、超时/限额、请求关联 | 响应片段、定稿候选、Provider request id、usage来源和规范化错误 | 重复/乱序/断流/不完整结尾可识别；流中止不证明远端推理或计费停止 |
| API-05 工具意图归一化 | F04-008、F03-012 | Provider结构化tool call及原逻辑生成关联 | 规范化工具意图/参数/调用轮次 | 不执行工具、不颁权限；参数重新校验；厂商格式差异不能绕过permissions/connections |

## 3. 请求输入快照

每次模型请求绑定Provider配置修订、模型标识/能力观察、凭证引用身份（不含秘密）、参数修订、输入来源/版本、逻辑生成关联、请求时间和超时策略。配置更新只影响后续请求；旧请求不得被新模型或新Key静默接管。

## 4. 错误与状态

至少区分配置无效、凭证缺失/拒绝、权限拒绝、能力不支持、限流、明确Provider错误、超时、断连、流式不完整、响应解析失败、usage未知、请求结果未知、回执保存失败。具体枚举由实现契约确定，不得把所有异常压成failed。

## 5. 重试与取消

- 只读模型请求的有限重试遵守Provider限流和用户策略。
- 工具意图触发的真实副作用由connections C02/C04管理；API适配器不得重发工具。
- 停止接收流、关闭本地HTTP连接和远端取消是不同能力；仅Provider确实支持时才声明远端取消。
- 超时/断连后按原request/Operation关联查询；无法确定时保持unknown。
- 故障切换不能绕过模型能力、数据外发、费用和授权约束。

## 6. 测试门槛

替身覆盖401/403/429、超时、断连、重复/乱序分块、不完整结束、未知usage、工具意图格式差异和凭证缺失。真实Provider测试另记录端点、模型、日期、费用影响和证据；替身测试不能宣称真实服务可用。API-07需独立本地模型运行时实验。
