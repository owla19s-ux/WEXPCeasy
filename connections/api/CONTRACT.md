# connections/api 业务子契约（2026-11-01）

- 上级owner：connections。细化Provider适配器，不创建第二Operation账本。
- 对应功能：F04-001～013及F03-008/F03-012。
- 状态：B候选语义；真实Provider、流式、限流和本地Runtime需C实验；费用/自动切换受PRD-D11约束。

## 1. Owner与边界

connections/api拥有Provider配置、模型目录/能力观察、请求协议适配、流式解析、厂商错误映射和usage来源记录。shared/credentials拥有秘密值；API只保存凭证引用。AI拥有Agent/角色配置和工作模型引用；conversations拥有逻辑生成、消息及输入快照；connections宿主拥有Operation/attempt/receipt/observation；workflows拥有Task/运行状态。工具意图是结构化提议，不是工具执行。

## 2. 能力子契约

| 锚点 | F映射 | 输入 | 输出/权威事实 | 生命周期与异常 |
|---|---|---|---|---|
| API-01 Provider配置 | F04-001/005 | Provider类型、端点、协议版本、非秘密参数、预期修订、凭证引用 | Provider连接配置修订 | 凭证明文不进入配置/日志；更新不重定向在途请求 |
| API-02 Model/Capability目录 | F04-003/004 | Provider实例、模型标识、能力探测/静态元数据 | 模型目录项、能力声明、来源和验证时间 | 未知能力不显示支持；探测失败不等于模型不存在 |
| API-03 凭证与连接测试 | F04-002/006 | 凭证引用、目标Provider/Model、测试动作 | 可用性/拒绝原因/请求观察 | 真实联网测试是受控Operation；Key不回显 |
| API-04 请求与流式解析 | F04-007、F03-008 | 本轮模型快照、输入、参数、超时/限额、请求关联 | 响应片段、定稿候选、Provider request id、usage来源和规范化错误 | 重复/乱序/断流/不完整结尾可识别；中止流不证明远端推理/计费停止 |
| API-05 工具意图归一化 | F04-008、F03-012 | Provider结构化tool call及逻辑生成关联 | 规范化工具意图/参数/调用轮次 | 不执行工具、不颁权限；参数重新校验 |
| API-06 用量与限额观察 | F04-010 | Provider usage/账单观察、模型/请求关联、计量单位和来源 | 原始用量、估算用量、未知值及计量来源 | 未返回费用保持未知；估算不冒充账单；预算策略由workflows/用户政策决定 |
| API-07 本地模型Provider | F04-013 | 本地服务端点、模型标识、运行环境观察 | 与远端Provider同类的能力/请求/错误投影 | WEX不默认下载模型或管理GPU Runtime；进程/资源管理另行实测 |
| API-08 模型路由与选择 | F04-009 | 用户/Agent选择、能力要求、Provider可用性、配置修订、数据出口范围 | 选中模型与路由原因/候选失败观察 | 不能按名称猜能力；路由不得绕过来源外发、权限和预算约束；在途请求固定旧快照 |
| API-09 超时、重试与降级 | F04-011 | 原请求关联、错误类别、Provider retry-after、用户策略 | 新attempt或明确不重试的观察 | 仅可重试模型请求；工具Operation不由API重试；超时/断连结果unknown时先查原请求 |
| API-10 模型故障切换 | F04-012 | 原模型失败证据、允许的候选模型、能力/数据出口/预算策略 | 新路由决定和独立请求快照 | 切换是新请求，不改写原请求；不自动切换除非策略明确允许；费用和来源政策未定时保持阻断/询问 |

## 3. 请求输入快照

每次模型请求绑定Provider配置修订、模型标识/能力观察、凭证引用身份（不含秘密）、参数修订、输入来源/版本、逻辑生成关联、请求时间和超时策略。配置更新只影响后续请求；旧请求不得被新模型或新Key静默接管。

## 4. 错误、取消与恢复

至少区分配置无效、凭证缺失/拒绝、权限拒绝、能力不支持、限流、明确Provider错误、超时、断连、流式不完整、解析失败、usage未知、请求结果未知、回执保存失败。停止接收流、关闭本地连接和远端取消是不同能力；仅Provider真实支持时声明远端取消。unknown按原request/Operation查询，不盲重发。

## 5. B评审结论与测试门槛

原API-06把usage、重试和故障切换合并，已拆为API-06/08/09/10，以分别绑定F04-010/009/011/012。自动故障切换不能绕过能力、数据外发、费用和授权约束。替身覆盖401/403/429、超时、断连、重复/乱序分块、不完整结束、未知usage和工具意图格式差异；真实Provider另记录端点、模型、日期、费用影响与证据。
