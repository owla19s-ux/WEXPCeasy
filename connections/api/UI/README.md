# connections/api/UI

API 模块专属配置面板的维护位置，由 WEX 配置页挂载。仅有实际专属交互时实现。

**历史（2026-10-30）**：当时本子目录只有职责说明。当前 `connections/api/src/` 已有正式 Provider/Model 领域代码；但 `UI/src/workbench.tsx` 中 API 与模型设置按钮仍禁用。不能把领域能力存在当作专属设置面板已完成，也不为该子目录预建空 UI。目录不等于运行时数据路径。

[源码目录与 Windows 数据要求](../../../docs/A1-正式产品设计/架构与决策/源码目录与Windows数据规则-2026-10-30.md)

修改原则：实现与必要测试按实际需要就近添加；不预建技术分层。模块专属 UI 随模块，内置页面集中在顶层 UI。实现后补充具体入口和验证方式。
