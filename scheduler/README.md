# Scheduler｜独立调度器模块施工入口

**状态：新规划的顶层独立模块，尚无正式产品源码或测试。** 不等同于旧 `workflows/runtime/` 研究契约的自动迁移。

## 模块职责
- 负责任务调度、派发协调、等待、重试、取消、恢复、资源占用与运行状态。
- 可服务独立任务及多个 Context、多个工作流；不以自由格子编辑器为运行前置。
- 通过公开能力消费工作流定义、连接能力和权限判断；不拥有连接器 Operation 回执、Agent 配置或 Context 本体。
- Context 可按需添加或关联调度能力；关联不等于自动执行授权。

## 施工要求
- 0.1.1 不开发正式调度器，按后续版本规划进入施工。
- 与 `workflows/`、`connections/`、`permissions/` 的职责冲突必须先核对现行产品决策，再确定接口。
- 正式施工时再建立 `src/` 与 `tests/`；不预建空目录或伪实现。
- 未获批准的高风险自动操作不因调度器存在而放行。

## 验收门槛
独立任务调度、跨 Context 隔离、幂等派发、取消竞态、重启恢复、资源冲突、权限复核和可执行测试。当前均未宣称通过。
