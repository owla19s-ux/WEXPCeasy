# environments｜工具与开发环境管理

> **模块地位（2026-11-07 用户确认）**：本目录正式列入 WEXPCeasy 的**独立源码维护域**，与 `connections/` 并列，不是 Local 连接器子目录。当前仅创建 README 以固定职责和施工入口；**没有 `src/`、测试、可运行环境管理器或安装能力**，不得将目录存在当作实现证据。

## 业务职责与范围

- 负责本机开发/工具环境的登记、检测结果和版本观察、用户选择及环境与工具的可用性描述；当获批完整环境管理功能时，负责安装计划、安装状态、依赖与版本策略、进度/取消、修复、升级/卸载、失败恢复及可核验的持久化业务记录。
- 0.1.1 只按既有已确认范围核对**环境目录选择、已有环境检测/识别、配置和 Context 关联**的必要缺口。完整自动下载安装、依赖管理、系统 PATH/注册表修改、升级/卸载/回滚尚未获本次版本施工授权。未来完整能力应由版本计划和具体验收规格单独确定；不因本 README 自动施工。
- 允许未来同时管理外部已存在环境、用户指定的工具环境目录与合法的系统级安装；不默认所有工具能做便携安装或保证系统盘零写入。**源码目录 `environments/` 不等于运行时工具安装目录**。

## 与现有 owner 的边界

| owner | 拥有 | 不拥有 |
|---|---|---|
| `environments/` | 环境生命周期、环境登记与版本/状态业务权威；后续获批的安装任务状态、恢复规则 | 直接绕权执行 OS 命令、第二份 Operation/权限账本 |
| `connections/local/` | 受控本机文件、目录，以及未来经独立批准的进程/工具/安装器执行适配，返回真实观察 | 环境安装计划、策略、版本选择、环境业务登记及恢复权威 |
| `connections/src/` | 公共连接配置、授权接点与 Operation/attempt/receipt 的受控记录 | 环境管理业务数据及软件包安装决策 |
| `app/` | 可信 Windows 原生入口、用户确认与宿主生命周期接线；WEX 本体安装见 B3 D-09 | 环境管理状态权威、GitHub/Local 的协议实现 |
| `space/` | Context 对环境/工具的引用、绑定和使用选择 | 工具包体、环境安装结果或 OS 执行权限 |
| `permissions/` | 授权、拒绝、撤权与审计 | 安装业务状态或操作效果推断 |
| `UI/settings/` | PC 设置左侧分类/子类及右侧详细环境配置页面挂载 | 擅自安装工具、存储第二份环境权威 |

**调用方向**：用户/Agent 的环境管理请求 → `environments` 的公开业务端口/计划检查 → 可信 `app` 原生确认与 `permissions` → `connections` 受控 Operation → `connections/local` 具体执行 → 观察证据回传 `environments`。流程只是职责说明，不是本版已实现的工作流或 API 签名。环境管理不能因为工具已发现就视为安装/可执行/已授权成功。

## 文件与目录治理

- 产品源码、公开端口、模块测试以后按批准功能逐步放在 `environments/src/` 和 `environments/tests/`；**当前不创建无行为的空壳**，不预先冻结类名、持久化结构或 IPC。
- 工具环境实际安装位置由用户选择或引用既有位置，须与 WEX 程序安装目录、公共数据根分离；真实缓存、下载、系统例外遵守 Windows 数据路径规定。
- 如新增模块跨域导入，遵守公共 `src/index.ts` 端口及边界工具约束；不得让 `shared` 或 `app` 替环境业务保存权威数据。
