# environments｜工具与开发环境管理

> 独立顶层业务 Owner，与 [Connections](../connections/README.md) 并列，**不是 Local 连接器**。版本状态见 [A2](../docs/A2-版本与工程状态/0.1.1/功能与工程状态总表.md)，长期需求见 [A1 F06](../docs/A1-正式产品设计/产品功能总表.md)。

## 现状（2026-11-08）

本目录已确立职责入口，但尚无已证实的 `src/index.ts`、正式公开服务、持久业务记录或模块测试；目前**不能宣称已实现可运行环境管理器**。README 和目录不是实现证据。

## 职责与分工

| Owner | 职责 |
|---|---|
| Environments | 现有工具/环境登记、识别与版本状态、选择、生命周期；未来经批准的安装/更新/恢复计划及业务结果 |
| Local | 受控本机文件/目录；未来批准的进程/安装器 OS 执行适配，不拥有环境安装策略 |
| Connections | 公共受控调用、Operation/attempt/Receipt，不保存环境业务权威 |
| App | 可信 Windows 原生入口、实际用户确认与宿主生命周期 |
| Space | Context 对工具/环境的引用与选择，不拥有安装状态或执行权限 |
| Permissions | 行为授权、拒绝及撤权，不推断安装已成功 |
| UI | 显示配置、识别、进度和结果，不自行执行系统修改 |

程序安装目录、公共数据根、工作区 Space 目录与实际工具环境位置必须分离；不承诺所有工具零系统盘写入。

## 版本边界与施工门槛

0.1.1 仅在已批准范围内核定已有环境目录/检测/选择及 Context 关联的最小输入输出，**F06-009/010 的具体字段、用户操作与环境识别/选择边界尚待收敛**。现有 Space 地址登记与 Local 读取不能当作真实 Environment Manager。完整自动下载安装、升级、卸载、修复、依赖解决、提权、PATH/注册表和回滚不自动进入本版。不得为显示“已开工”预建空 src/tests 或定义未经确认的权限策略。

下一步先核 A1 F06-009/010 与 A2 D-10 的最小范围和使用入口，再按本 owner 新建可验证的公开 API 与测试；受控外部副作用只复用 Local/Connections/Permissions。尚无验收通过证据。
