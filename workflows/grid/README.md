# 自由格子工作流｜模块施工入口

**状态：新规划的独立模块，尚未建立正式产品源码或测试。** 现有 `workflows/editor/prototype/` 是历史原型，不自动成为本模块实现。

## 模块职责
- 维护工作流定义、自由格子节点、正交连线、布局、草稿修订及编辑状态。
- 以公开能力提供工作流定义与视图数据；不得拥有调度器运行状态、任务执行权威或权限账本。
- Context 可引用或添加本能力；Context 仅维护组合引用，不复制工作流权威数据。
- 不将节点视觉连接直接等同于执行依赖；运行语义须由显式契约确定。

## 施工要求
- 0.1.1 不实施正式自由格子工作流，计划进入 0.1.2。
- 正式施工前按功能项确定数据模型、公开能力、保存恢复、并发冲突、权限与可执行验收。
- `src/`、`tests/` 在开始正式施工时按需建立；不创建空壳文件。
- 详细研究与实验保存在 `docs/research/` 或 `experiments/`，不把候选设计当作已批准接口。

## 验收门槛
独立编辑与保存恢复、修订冲突、节点/连线约束、Context 关联、与调度器分离及可复现测试。当前均未宣称通过。
