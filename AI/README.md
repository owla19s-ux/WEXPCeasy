## 配置、职责、运行必须分开

- [roles/](roles/README.md) 维护角色配置与适用范围内的职责关联。角色、执行主体、模型、连接、会话是不同概念；同一配置可用于多次运行，不能共用一份可变运行状态或所有项目的授权。
- 角色/Agent 可独立存在，也可被多个 Context 选择。选择关系由 `space` 维护；具体职责关联由角色域维护，不建立两份相互同步的成员表。
- `connections/api` 维护 Provider 协议和实际模型调用；AI 配置只引用连接，不复制 Key。换模型不自动换执行身份、职责或权限。
- `workflows` 决定任务交接与推进；实际动作由内置执行适配器或外部 Agent 执行。外部 Agent 的循环、Session 和内部工具不归 WEX 的 AI 配置所有，WEX 保存其关联入口和观察证据。
- 普通对话生成的组织归 `conversations`，不强制经任务调度。未来若确需 WEX 内部多回合工具循环，归属和生命周期还要单独试验；不能把持续施工目标直接写成已实现的内部 Agent 引擎。

角色记忆、公共策略库及长期运行机制保留长期研究地位；本批不冻结记忆数据模型或新增目录。模型已看到的信息不会因撤权自动遗忘，后续取数由权限边界限制。
