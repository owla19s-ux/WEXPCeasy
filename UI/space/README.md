## G1：Context 资料关联

页面需区分关联外部文件/目录、导入持久副本、会话临时附件和 Task 工作产物。关联原文件不复制；导入副本必须由用户明确触发并显示来源；移除 Context 关联不删除源文件、不撤权、不停止 Task。显示的资源路径/名称不能作为稳定身份，失联和版本变化需明确提示。
