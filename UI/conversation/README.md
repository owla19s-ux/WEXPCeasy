## G7：输入与附件交互

页面负责文本输入、系统文件选择、拖入/粘贴、附件预览/移除及来源/可用性提示。附件可作为本轮临时输入，也可由用户明确选择关联原文件或导入持久资料；三者不能默认等同。实际读取通过 App/Connections 窄能力，Renderer 不直接访问 Node、任意文件路径、数据库或凭证。生成派发后输入快照不可被后续编辑改写。
