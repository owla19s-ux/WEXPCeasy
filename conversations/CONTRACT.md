

## 2026-11-01：F03逐项能力锚点与补充契约（B，待评审）

以下编号用于F03追踪，不冻结TypeScript签名、IPC、存储schema或流协议。conversations仍是消息/序列项/逻辑生成的唯一owner；Provider协议归connections/api，Operation归connections，Task归workflows，UI只呈现。

| 能力锚点 | F映射 | 输入与权威输出 | 生命周期/异常约束 |
|---|---|---|---|
| CV-01 会话生命周期与历史 | F03-001 | 会话身份、可信主体/入口、操作意图 → 会话身份/修订、获准历史投影 | Context/Task可空；创建重复按原意图核对；无权与不存在等价；归档/删除不级联删除来源资料 |
| CV-02 消息与轮次持久化 | F03-002 | 会话修订、消息输入、逻辑轮次关联 → 消息版本、保存结果和来源引用 | 区分未提交/已提交/提交未知；未知按原关联回读，不新建轮次 |
| CV-03 稳定序列项 | F03-003 | 定稿消息版本及拆分内容 → 稳定序列项身份、顺序、所属消息版本 | 身份不由渲染顺序生成；排序变化不改身份；局部修订产生新版本 |
| CV-04 局部选择与引用 | F03-004 | 序列项/消息版本、选择范围、引用目的 → 绑定来源版本的引用 | 引用不等于采纳、授权或执行；源修订变化时保留原版本或明确失效 |
| CV-05 分支讨论 | F03-005 | 源消息/序列项版本、分支意图 → 独立分支身份及回链 | 分支不覆盖主线；合并/采纳必须显式提交 |
| CV-06 修改、重发与局部修订 | F03-006/F03-016 | 原消息/序列项修订、修改内容、重发意图 → 新版本/新逻辑生成及来源关系 | 重发不复用旧工具授权，不重复旧Operation；旧副作用仍保留；并发冲突拒绝覆盖 |
| CV-07 追加与排队 | F03-007 | 追加内容、目标会话和当前生成关联 → 队列项/后续输入版本 | 已派发输入快照不可变；取消只移除未派发项；不声称Provider接受动态追加 |
| CV-08 流式接收与定稿 | F03-008 | 绑定本逻辑生成/attempt的可信片段 → 暂态片段、定稿消息和来源证据 | 重复/乱序按来源定位；断流不显示完整成功；提交未知先回读，不重调模型 |
| CV-09 停止与恢复 | F03-009 | 逻辑生成及原Operation定位 → 停止请求、外部确认/未知观察和恢复线索 | 停止显示、停止等待、远端取消分开；迟到结果归原生成；未知不重派、不回滚 |
| CV-10 背景与模型快照 | F03-010 | 获准Context/Agent/模型引用及修订 → 本轮不可变输入依据 | 切换背景只影响新生成；旧轮次保留原依据；读取/外发仍需当前判权 |
| CV-11 附件与来源 | F03-011 | 用户选择的文件/图片/文本附件引用、来源版本和用途 → 临时附件/原文件引用/持久导入副本的明确类型 | 临时附件不自动进入Context；引用与导入不同；读取重新判权；字节/路径不由消息JSON自造 |
| CV-12 工具意图往返 | F03-012 | Provider结构化工具意图 → 经permissions/connections执行后的真实结果引用 | 模型文本不是命令；拒绝/不可用/未知按事实回注；一轮生成可关联0..N个Operation |
| CV-13 显式转Task | F03-013 | 用户明确采纳的内容、目标范围和请求关联 → workflows返回的Task身份/修订引用 | conversations不写Task；重复请求按原关联核对；创建Task不自动启动 |
| CV-14 会话检索 | F03-014 | 获准查询条件、主体/入口和分页依据 → 会话/消息/序列项最小投影 | 索引新鲜度/授权代次受控；撤权后缓存失效；跨域查询由各owner提供 |
| CV-15 序列项采纳/拒绝 | F03-015 | 稳定序列项版本、用户决定和理由（可选） → 该项采纳/拒绝/待讨论修订 | 只改变序列项决定；不自动修改需求、创建Task、批准权限或执行工具 |

组合约束：消息输入、逻辑生成、Provider请求、工具Operation和消息定稿是不同对象。对话可无Context/Task；任何真实副作用均经过connections受控入口；恢复由原关联回读，不以重发消息代替。

准备度：CV-01/02/04/05/07/10/12/13稳定语义可先实现；CV-03/06/11/14/15需独立测试；CV-08/09真实流式、断流和取消竞态仍为C，追加/片段保留政策受D05约束。
